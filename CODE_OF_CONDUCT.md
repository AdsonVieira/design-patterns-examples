# Código de Conduta

## Nosso compromisso

Participantes deste projeto comprometem-se a manter um ambiente aberto, acolhedor e livre de assédio para todos, independentemente de idade, deficiência, etnia, identidade e expressão de gênero, nível de experiência, educação, status socioeconômico, nacionalidade, aparência, raça, religião ou identidade e orientação sexual.

## Padrão adotado

Este projeto segue o [Contributor Covenant](https://www.contributor-covenant.org/), versão 2.1. O texto completo está em:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Aplicação

Comportamentos inadequados podem ser reportados ao mantenedor do repositório pelas issues do GitHub ou pelo contato indicado no perfil do mantenedor. Todas as denúncias serão analisadas e responderão de forma justa.
