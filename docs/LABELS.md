# Labels sugeridas (GitHub)

Aplique manualmente no repositório em **Settings → Labels**, se ainda não existirem:

| Label | Cor sugerida | Uso |
|-------|--------------|-----|
| `good first issue` | verde claro | Tarefas pequenas para primeiro PR |
| `documentation` | azul | README, CONTRIBUTING, templates |
| `pattern` | roxo | Novo padrão ou melhoria em exemplo |
| `bug` | vermelho | Compilação ou comportamento incorreto |

Issues de CI e governança podem usar `documentation` e `good first issue`.
